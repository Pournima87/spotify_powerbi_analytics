# 🎵 Spotify Streaming Analytics Dashboard (Power BI)

An interactive and insight-driven Power BI dashboard built to analyze Spotify streaming data, artist performance, track characteristics, and listener behavior.

Designed with a strong focus on **real-world BI practices**, including data modeling, context-aware calculations, and executive storytelling.

---

## 🚀 Problem Statement
Spotify generates massive volumes of streaming and engagement data.  
However, raw data alone cannot answer:

- Which artists are truly growing?
- What audio features influence popularity?
- When are users most engaged?
- How does performance change over time?

This dashboard converts raw data into **clear, actionable intelligence**.

---

## 🎯 Project Objectives
- Measure **track and artist performance**
- Understand **audio characteristics** such as danceability, energy, and valence
- Analyze **listening patterns and engagement behavior**
- Track **Year-over-Year growth and momentum**
- Enable quick, interactive exploration for decision-makers

---

## 📊 Key Features
- Interactive slicers (Artist, Track, Year, Platform)
- Executive KPI summary cards
- Top artists & tracks ranking
- Year-over-Year comparison
- Listening behavior insights (skip rate, shuffle rate, hourly activity)
- Drill-through for deep dive analysis
- Dynamic report tooltips
- Clean and modern dark-themed UI
